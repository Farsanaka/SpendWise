# SpendWise

SpendWise is an expense tracker app. Add your expenses under custom 
categories, then see your totals and spending patterns visualized 
with graphs.

## Tech stack

- React
- Tailwind CSS
- Redux Toolkit (RTK)

**Coming soon:** TypeScript, Node.js (backend + auth), Playwright (testing)

## Features

- **Dashboard** — view your transaction totals and a graph for quick 
  analysis
- **Budgets** — set a budget per category and track progress
- **Categories** — full CRUD (create, edit, delete your own categories)
- **Analytics** — compare income vs. expense over time

## How to run locally

\`\`\`bash
git clone https://github.com/Farsanaka-Edstem/SpendWise
cd spendwise
pnpm install
pnpm dev
\`\`\`
